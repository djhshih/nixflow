# Nixflow

This project is an experiment to evaluate how to use [Nix][nix] or [Nickel][nickel]
to build workflows by compiling Nix or Nickel config files to the [Common
Workflow Language][cwl].

[nix]: https://nix.dev/tutorials/nix-language.html
[nickel]: https://nickel-lang.org/
[cwl]: https://www.commonwl.org/

See `nix/README.md` and `nickel/README.md` for details.
